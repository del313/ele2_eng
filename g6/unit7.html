📌 因果連接詞：Because vs. So
  • Because 引導的是「原因」。
  • So 引導的是「結果」。
  • 注意：在英文中 because 和 so 通常不會同時出現在同一個句子裡。
連接詞用途範例
because接原因I ate because I was hungry.
so接結果I was hungry, so I ate.
